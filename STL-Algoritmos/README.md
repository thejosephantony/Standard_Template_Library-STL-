# STL e Estruturas de Dados em C++

Mini-projeto didático para estudar STL e estruturas de dados comuns em problemas de programação competitiva / juiz online.

## Como compilar

No terminal, dentro da pasta do projeto:

```bash
g++ -std=c++17 main.cpp src/*.cpp -Iinclude -o stl_estudo
```

No Windows PowerShell:

```bash
g++ -std=c++17 main.cpp src/*.cpp -Iinclude -o stl_estudo.exe
.\stl_estudo.exe
```

## Conteúdo

- `vector` e `string`
- matriz com `vector<vector<int>>`
- `pair` e `struct`
- `sort`, `reverse`, `find`, `count`, `min_element`, `max_element`
- `lower_bound` e `upper_bound`
- soma prefixada
- `stack`, `queue`, `deque`
- `set`, `multiset`
- `map`, `unordered_map`
- `priority_queue`
- lista de adjacência para grafos
- DSU / Union-Find

## Observação

Este projeto não é para resolver um único problema. Ele serve como base de consulta para vários tipos de problemas de estruturas de dados.
